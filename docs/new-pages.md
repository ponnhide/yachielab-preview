# Sheetから新しいページを作る

新規ページも既存ページと同じ `Custom menu` → `Update the current page` で作成・更新します。

1. previewのスプレッドシートで `template` タブを複製します。プルダウン・書式・パラメータの式をそのまま使えます。手作業でタブを追加する場合も、同じ `Lab` / `Language` / `Function` と各Functionの列構成を用意してください。
2. タブ名を新しいページ名に変更します。たとえば `seminars` なら公開URLは `seminars.html` です。先頭は英小文字、続きは英小文字・数字・`_`・`-`、合計64文字以内にします。予約名や既存のタブ・ページと重なる名前は使えません。
3. 複製したサンプル行を実際の本文へ変更します。H1のTitleをページタイトルにし、必要な本文行を追加します。
4. そのタブを選んだまま `Custom menu` → `Update the current page` を実行します。初回のHTML生成とGitHubへの保存成功後、名前は `item list` のSheet列（D）とPage列（E）の両方へ自動登録されます。Actionsの検査・配信完了後に公開サイトで確認してください。

タブを追加・編集した時点では公開されません。D・E列を手作業で準備する必要もありません。両列は独立した一覧なので、同じ名前が同じ行に並ぶとは限りません。既存の名前は重複登録せず、不足する列だけを補います。初回生成では汎用の `blank.html` に現在のheader・footer・sidebar・mobilemenuと本文を組み込み、その後は同じ更新ボタンで本文を差分更新します。片方の登録だけが失敗した場合や、以前のPage列だけの登録も、同じタブで更新すると補完されます。更新に失敗した場合は表示されたエラーを確認し、入力を修正して再実行してください。

言語はEnglish・Japanese・Chinese、全言語共通の行はCommon、所属はUBC・Osaka・Allで指定します。独立ページでは空のLabセルが本文の終了を意味するので、続きの行を作るときに途中のLabを空にしないでください。Sheetで指定できる表示設定と、画像更新・キャッシュの仕組みも既存ページと共通です。

ページを作るだけではナビゲーションの項目は増えません。リンクを表示したい場合はheader・sidebar・mobilemenu等の該当タブへ明示的に追加し、そのタブで `Update the current page` を実行します。ホーム画面の大きなメニュータイルは別の構成なので、新規ページの自動登録対象には含みません。新ページへの内部リンクには、ブラウザで現在の言語と所属が引き継がれます。

意図的に更新対象から外している既存タブは、名前を変えても自動登録しません。非登録の既存HTMLを同名の新規タブで引き継ぐこともありません。一括更新や共通部品の更新で、非登録のタブがまとめて登録されることはありません。登録されたページのタブ名を後から変えても、既存URLやリンクは自動で移動しないため、変更前にリンクと公開ファイルを確認してください。

新ページのHTMLはCIが自動で検査・ビルド対象へ含めます。ページ数の固定上限はなく、既存ページと同じ共通JSによって言語・所属の切り替えとロゴ境界の表示が動作します。汎用テンプレートはContact専用のiframeサイズ指定を読み込まず、Post行のSNS埋め込み用コントローラーを読み込みます。SNSのPostがないページでは外部SNSスクリプトを追加しません。
