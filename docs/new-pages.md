# Sheetから新しいページを作る

previewのスプレッドシートで `Custom menu` → `Create a new page` を選び、ページ名（slug）と表示タイトルを入力します。slugはURLのファイル名になり、たとえば `lab_projects` なら `lab_projects.html` になります。予約名や既存のページ名は使用できません。

作成操作は、本文用のSheetテンプレートをネイティブにコピーして新しいタブを作り、`item list` のE列へページ名を登録します。まず新しいタブの内容を編集し、`Update the current page` を実行してください。HTMLがまだない場合は汎用の `blank.html` を使って初回生成し、現在のheader・footer・sidebar・mobile menuを組み込みます。その後は同じ操作で本文を差分更新できます。

本文は既存ページと同じ `Lab` / `Language` / `Function` と各Functionの列を使います。言語はEnglish・Japanese・Chinese、全言語共通の行はCommon、所属はUBC・Osaka・Allで指定します。独立ページでは空のLabセルが本文の終了を意味するので、続きの行を作るときに途中のLabを空にしないでください。Sheetで指定できる表示設定と、画像更新・キャッシュの仕組みも共通です。

ページを作るだけではナビゲーションの項目は増えません。リンクを表示したい場合はheader・sidebar・mobilemenu等の該当タブへ明示的に追加し、`Update shared components` を実行します。ホーム画面の大きなメニュータイルは別の構成なので、新規ページの自動登録対象には含みません。新ページへの内部リンクには、ブラウザで現在の言語と所属が引き継がれます。

`item list` のE列に登録されていない既存タブやページは、引き続き意図的に更新対象から除外されます。新規ページの導入を理由にすべてのタブを登録する必要はありません。ページ名を後から変えても既存URLやリンクが自動で移動するわけではないので、変更前にリンクと公開ファイルを確認してください。

作成途中でエラーが出た場合、コピー済みのタブは復旧用に残ります。タブ名とE列の登録を確認し、必要な修復をしてから通常更新してください。E列以外には独立した選択肢の一覧があるので、登録のために行全体を書き換えないでください。

新ページのHTMLはCIが自動で検査・ビルド対象へ含めます。ページ数の固定上限はなく、既存ページと同じ共通JSによって言語・所属の切り替えとロゴ境界の表示が動作します。汎用テンプレートはContact専用のiframeサイズ指定を読み込まず、Post行のSNS埋め込み用コントローラーを読み込みます。SNSのPostがないページでは外部SNSスクリプトを追加しません。
